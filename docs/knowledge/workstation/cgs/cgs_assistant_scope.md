What this assistant can and cannot do.

**Read-only.** It never releases, assigns, reassigns, sets maintenance, marks a key, or changes anything -- it answers questions and links to the right page for you to act on yourself.

**No names in questions.** A question containing a real student's name is refused, for privacy -- search by Student ID (8 digits) or seat number instead.

**Understands informal questions.** You can type the way you would message a colleague ("how many seat will be release in nov", "J2 got seat or not", "pls release seat 252"). Every answer ends with an "Interpreted as" line showing the exact question it answered; when it is not sure, it also offers up to three "Did you mean" questions you can tap instead -- tapping one never uses the AI quota.

**Links, not actions.** Every answer that has a relevant page links to it (a seat's own page, the filtered list a number came from, or the Insights page) -- the link is where you actually make a change.

**Knowledge, not judgement.** It answers from the system's own written rules and live data only; it never guesses at a policy the text does not state, and says so plainly when a question falls outside what it has been given.

**Always live, always the same numbers as the Insights page.** Every number in every answer is read from the database at the moment you ask -- nothing is cached or pre-computed, in either the page or the chat. The Workstation Management pages and the Insights page also refresh their own numbers every 15 seconds while open, so after any seat or key action by anyone the page, the chat and the Insights charts all show the same new numbers. Questions like "which programmes use workstations most", "male versus female occupancy", "how many keys are not requested", "how long have students been in their seats", "when do candidacies expire", "seats by status per block" and "when are keys due back" read the exact same statistics functions the Insights page's own charts read, so the chat and the page can never disagree.
