Which reason to choose for a seat action, by group. Every reason below is the exact wording shown in the dropdown -- nothing here is paraphrased.

Release -- Termination (gives the student 5 working days to vacate, under the Postgraduate Workstation Term of Use clause 16):
• Deferment -- choose this when the student has deferred their studies.
• Change programme to Coursework -- choose this when the student has changed to a coursework programme, which does not carry a workstation entitlement.
• Change programme mode to Part-Time -- choose this when the student has changed to part-time mode.
• Graduated -- choose this when the student has graduated.
• Withdrawn -- choose this when the student has withdrawn from the programme.
• Dismissal -- choose this when the student has been dismissed.
• De-registered -- choose this when the student has been de-registered.
• Under disciplinary action -- choose this when the student is under disciplinary action that affects their workstation use.
• Absent without prior approval -- choose this when the student has been absent without prior approval.
• Other reason deemed appropriate by the University -- choose this for any other Termination-group reason not listed above.

Release -- Immediate correction (releases the seat at once, no notice period):
• System error -- choose this when the seat was allocated by a technical fault, not a real request.
• Allocation error -- choose this when the wrong student or the wrong seat was allocated.
• Student has vacated -- choose this when the student has already left the seat.

Reassign:
• Room maintenance or repair -- choose this when the student must move out of a room going into maintenance or repair.
• Allocation error -- choose this when the student is in the wrong seat and needs to move to the correct one.
• Special case approved by CGS -- choose this when CGS has approved an exceptional move.
• Other -- choose this for any other reason, and write a remark.

Assign Student (a student with no seat only -- see guidance:cgs_reassign/cgs_assign for when to use which):
• Student unable to use the system -- choose this when the student cannot select a workstation themselves.
• System error -- choose this when a technical fault prevented the student from being allocated normally.
• Special case approved by CGS -- choose this when CGS has approved an exceptional manual assignment.
• Other -- choose this for any other reason, and write a remark.

Set Maintenance:
• Repair needed -- choose this when the seat or its furniture needs repair.
• Cleaning or renovation -- choose this when the seat is out of use for cleaning or renovation.
• Equipment fault -- choose this when equipment at the seat is faulty.
• Other -- choose this for any other reason, and write a remark.

Release Hold (on a seat Awaiting Key Return):
• Key lost -- choose this when the student's locker key is lost and will not be returned.
• Lock replaced -- choose this when the lock was replaced instead of waiting for the key.
• Other -- choose this for any other reason, and write a remark.

Withdraw Termination (cancels an active termination notice):
• Issued by mistake -- choose this when the notice should never have been issued.
• Student situation changed -- choose this when the situation that caused the notice no longer applies.
• Other -- choose this for any other reason, and write a remark.

If unsure, choose Other and write a remark.
