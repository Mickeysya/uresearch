When you return your workstation from the Workstation page, choose a reason:
• Changing to another workstation -- choose this when you want a different seat (return this one first, then select another).
• No longer need a workstation -- choose this when you no longer need one at all.
• Completed study -- choose this when you have finished your studies.
• Other -- choose this for any other reason.

Returning releases the seat immediately, so it can be taken by someone else -- choose carefully. If your locker key is Collected, you still need to return the physical key to CGS; returning the workstation online does not return the key itself, and you cannot request a new key until the old one is returned.
