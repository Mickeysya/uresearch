Once your workstation seat is confirmed, you can request your locker key from the Workstation page. This marks the key as Pending Collection -- it does not hand you the key itself, you still collect it in person.

You have {{key_collection_days}} days from the request to collect it at the Centre for Graduate Studies (CGS), Monday to Friday, 8:00 AM - 5:00 PM (GMT +8.00). If you have not collected it after {{key_collection_reminder_days}} days, you get a reminder. If it is still uncollected after {{key_collection_days}} days, the request is cancelled automatically and you would need to request again.

You cannot request a new locker key while you still owe a return on a previous one -- return the outstanding key first.
