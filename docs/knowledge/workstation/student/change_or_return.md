You can return your workstation at any time from the Workstation page by choosing "Return Workstation" and a reason: Changing to another workstation, No longer need a workstation, Completed study, or Other. This releases the seat immediately and makes it available to other students again.

There is no self-service way to swap directly from one seat to another -- moving a student from one seat to a different one is done by the Centre for Graduate Studies (CGS) (a Reassign). If you want a different seat, return your current one first (or ask CGS to reassign you), then you are free to select an Available seat again, as long as you are still eligible.

If your locker key is Collected at the time you return your seat, you still need to return the physical key to CGS -- returning the workstation online does not return the key itself.
