On a seat's Seat Details page: "Mark as Collected" moves a Pending Collection key to Collected (the student has physically taken it). "Mark as Returned" moves a Return Pending key to Returned, which also frees the seat from Awaiting Key Return if that is why it was in that state. Both are done in person at the Centre for Graduate Studies (CGS) counter, Monday to Friday, 8:00 AM - 5:00 PM (GMT +8.00), when the student actually hands over or collects the physical key.
