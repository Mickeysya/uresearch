Seat statuses you may see on your own workstation:
• Available -- nobody holds it; you can select it.
• Pending -- someone has selected it and is within their confirmation window; it returns to Available automatically if they do not confirm in time.
• Occupied -- you (or another student) hold it and have confirmed it.
• Maintenance -- out of use for repair, cleaning or an equipment fault; cannot be selected or assigned.
• Awaiting Key Return -- the previous occupant's locker key is still outstanding; the seat only becomes Available again once CGS marks that key as returned.

Locker key statuses, and what can happen next:
• Not Requested -- you have not asked for a key yet. Next: request it, which moves it to Pending Collection.
• Pending Collection -- requested, waiting for you to collect it in person. Next: Collected (you pick it up), or Cancelled (uncollected too long).
• Collected -- you are holding the physical key. Next: Return Pending (once your seat is released or you are reassigned).
• Return Pending -- you owe its return to CGS. Next: Returned (you hand it back), or Overdue if the due date passes while still outstanding.
• Overdue -- a Return Pending key past its due date; not a separate stored status, just how an overdue Return Pending key is shown.
• Returned -- handed back to CGS and marked as such; the cycle for that key is complete.
• Lost -- CGS has written the key off (see guidance:key_lost); does not block you from requesting a new key for a future seat.
