The dismissal list is exported by CGS, processed by the Registry outside this system, and the result is uploaded here.

**CGS process.**
1. Open Candidacy Management > Dismissal List and, if needed, filter. **Export to Excel** exports exactly what the filters show (everything if none), and records the export.
2. Send the file to the Registry; they process it outside this system.
3. The Registry or CGS opens **Dismissal Upload**, chooses the file the Registry returns (.xlsx or .csv with a "Student ID" column), and checks the **preview**: Will be dismissed, Not a current candidate, Already dismissed, Unknown ID, Duplicate.
4. **Confirm**: students still on the list are marked dismissed and get an e-mail and bell at once; they leave the list. Students not in the file stay on it.

There is no keep status and no batch lock. I can't export or upload for you.

Source: CGS process (dismissal export and Registry upload).
