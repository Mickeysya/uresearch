**CGS process.** An appeal needs the official appeal form and, if you have them, up to {{cand_max_supporting}} supporting documents.
- The official appeal form must be an Excel file (.xlsx); it is required.
- Supporting documents can be Excel (.xlsx), PDF or Word (.docx) files.
- Each file can be at most {{cand_max_file_mb}} MB, and its content must match its file type or the upload is refused.
- Documents can only be added or changed on a draft or on a returned appeal.

If an approver returns your appeal for missing or unclear documents, replace them and resubmit; it goes back to the step that returned it.

Source: CGS process (appeal form rules); the Handbook does not list the documents. Form number or wording: ask CGS.
